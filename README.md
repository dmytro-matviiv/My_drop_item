# МійДроп: пошук товару за артикулом (Telegram-бот)

Пишете боту артикул, він відповідає звітом: назва, постачальник, дроп-ціна, наявність по розмірах, фото й посилання на товар на сайті МійДроп. Пошук іде лише серед постачальників, яких ви додали в бота. Каталоги зберігаються на диску й оновлюються у фоні.

## 1. Створити бота в @BotFather

1. Відкрийте в Telegram [@BotFather](https://t.me/BotFather) і надішліть `/newbot`.
2. Введіть назву (наприклад, «Мій пошук артикулів») і username, що закінчується на `bot`.
3. BotFather надішле **токен** виду `123456789:AA...`. Це `BOT_TOKEN`. Нікому його не показуйте.

## 2. API-ключ МійДроп

У кабінеті дропшипера МійДроп відкрийте розділ «Інтеграції» → «API» і скопіюйте ключ. Це `MYDROP_API_KEY`. Документація API: https://api.mydrop.com.ua (розділ «Версія для дропшиперів»).

## 3. Змінні середовища

| Змінна | Що це |
|---|---|
| `BOT_TOKEN` | токен від @BotFather |
| `MYDROP_API_KEY` | API-ключ МійДроп |
| `ADMIN_IDS` | ваш Telegram ID (можна кілька через кому). Адміністратор схвалює доступ іншим людям і отримує сповіщення про проблеми з ключем |
| `ALLOWED_USERS` | необов'язково: ID людей, яким доступ дозволено одразу, без запиту |
| `DATA_DIR` | тека для даних (список постачальників і кеш каталогів), за замовчуванням `./data` |
| `REFRESH_MINUTES` | як часто оновлювати каталоги, хвилин (за замовчуванням 15) |
| `TIMEZONE` | необов'язково, часовий пояс для «Дані оновлено» (за замовчуванням `Europe/Kyiv`) |

**Як дізнатися свій Telegram ID:** запустіть бота (можна поки з порожнім `ADMIN_IDS`) і надішліть йому `/start`. Він покаже ваш ID. Впишіть його в `ADMIN_IDS` і перезапустіть бота.

**Доступ для інших людей:** дайте людині посилання на бота. Коли вона надішле `/start`, вам прийде запит з кнопками «✅ Дозволити» / «❌ Відхилити». Після схвалення людина має такий самий доступ, як ви: шукає товари, додає й видаляє постачальників. Список людей і кнопки «🚫 Забрати» є в меню «👥 Користувачі» (його бачать лише адміністратори). Усі користуються вашим API-ключем МійДроп і спільним списком постачальників.

Ключі й токени зберігаються **лише** в змінних середовища (локально у файлі `.env`, який не потрапляє в git).

## 4. Запуск локально

Потрібен Python 3.12 (підійде й 3.10+).

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS
pip install -r requirements.txt
copy .env.example .env          # Windows; на Linux/macOS: cp .env.example .env
```

Заповніть `.env` і запустіть:

```bash
python -m bot.main
```

Тести (мережа не потрібна):

```bash
pip install -r requirements-dev.txt
pytest
```

## 5. Деплой на Railway

1. Завантажте код у свій репозиторій на GitHub (файл `.env` і тека `data/` туди не потрапляють, це прописано в `.gitignore`).
2. На [railway.com](https://railway.com) натисніть **New Project** → **Deploy from GitHub repo** → виберіть репозиторій. Railway сам знайде `requirements.txt`, версію Python з `.python-version` і команду запуску з `railway.json` (`python -m bot.main`).
3. Відкрийте сервіс → вкладка **Variables** → додайте `BOT_TOKEN`, `MYDROP_API_KEY`, `ADMIN_IDS`, `REFRESH_MINUTES=15`, `DATA_DIR=/data`.
4. **Volume** (щоб список постачальників, користувачі й каталоги не зникали після редеплою; бот сам пише дані на підключений Volume, навіть якщо DATA_DIR не задано): на полотні проєкту натисніть правою кнопкою на сервіс (або `Ctrl/⌘ + K`) → **Attach Volume** / **Create Volume**, вкажіть **Mount path** `/data`. Шлях має збігатися з `DATA_DIR`.
5. Сервіс перезапуститься сам. Якщо ні, натисніть **Deploy** / **Redeploy**.
6. **Логи:** сервіс → вкладка **Deployments** → останній деплой → **View Logs**. Після старту там буде рядок `Бот запущено…` і рядки `Каталог … оновлено: N товарів`.

Публічний домен і порт боту не потрібні: він працює через long polling. Запускайте **лише один** екземпляр бота з тим самим токеном, інакше Telegram видаватиме помилку конфлікту.

## 6. Як користуватися

- **➕ Додати постачальника:** надішліть будь-яке посилання на його магазин на МійДроп (`https://mydrop.com.ua/segeda_shop`, посилання на категорію, товар або `.../join/segeda_shop`). Або натисніть «Вибрати зі списку підключених». Постачальник має бути підключений у вашому кабінеті МійДроп.
- **📋 Мої постачальники:** список, кількість товарів, час оновлення й кнопки «🗑 Видалити».
- **🔄 Оновити каталоги:** оновити зараз (автоматично це відбувається кожні `REFRESH_MINUTES` хвилин).
- **👥 Користувачі** (лише адміністратор): хто має доступ, запити, кнопки «Дозволити» / «Забрати».
- **Пошук:** просто надішліть артикул, наприклад `art1.01`.
  - Регістр і пробіли не важливі: `ART 1.01` = `art1.01`. Крапки, дефіси й підкреслення важливі: `art1.01` і `art101` різні товари.
  - Спочатку шукається точний збіг з артикулом товару, потім з артикулом розміру (тоді цей розмір позначено ▶).
  - Якщо точного збігу немає, бот покаже до 5 схожих товарів кнопками. Тут крапки, дефіси й `_` уже ігноруються, тож `cap77` підкаже `CAP-77`.
  - Однаковий артикул у кількох постачальників: окремий звіт на кожен товар.
  - Якщо постачальник не заповнює артикули (як «Харків дроп»), надішліть ID товару: число з посилання `.../p/5566217`. Або просто перешліть посилання на товар: якщо постачальника вже додано, бот одразу покаже звіт.

Наявність береться з каталогу МійДроп, який оновлюється на їхньому боці із затримкою до ~15 хвилин. Точну кількість на складі бот не показує, лише «В наявності» / «Немає».

Якщо МійДроп відхилить ключ (невалідний або закінчилась підписка), бот один раз напише про це адміністратору в Telegram і далі шукатиме по останніх збережених каталогах.
